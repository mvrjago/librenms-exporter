# LibreNMS Exporter

A lightweight Flask-based web application for exporting and analyzing LibreNMS monitoring data from RRD files and the LibreNMS MySQL database.

The application provides a simple authenticated web interface for generating CSV/TSV reports for CPU usage, memory usage, and storage utilization.

## Features

* 🔐 User authentication with Flask-Login
* 📊 CPU usage reporting from LibreNMS RRD files
* 🧠 Memory usage reporting from LibreNMS RRD files
* 💾 Storage utilization reporting from the LibreNMS MySQL database
* 📁 CSV/TSV export
* 🐳 Docker support
* ⚙️ Environment-based configuration
* 🔧 Support for different LibreNMS RRD locations
* 📅 Configurable RRD reporting period
* 🖥️ Support for Linux and Windows storage partitions

## How It Works

LibreNMS Exporter reads monitoring data from two sources:

### RRD Data

CPU and memory reports are generated by reading LibreNMS RRD files using `rrdtool`.

```text
LibreNMS RRD
     │
     ▼
rrdtool
     │
     ├── CPU Exporter
     │
     └── Memory Exporter
             │
             ▼
          CSV Report
```

### MySQL Database

Storage utilization is retrieved directly from the LibreNMS MySQL database.

```text
LibreNMS MySQL
      │
      ▼
Storage Exporter
      │
      ▼
   TSV Report
```

## Installation

Clone the repository:

```bash
git clone https://github.com/mvrjago/librenms-exporter.git
cd librenms-exporter
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate it:

### Linux

```bash
source .venv/bin/activate
```

### Windows

```powershell
.venv\Scripts\Activate.ps1
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

## Configuration

Copy the example environment file:

```bash
cp .env.example .env
```

On Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Edit `.env` and configure your LibreNMS environment.

Example:

```env
SECRET_KEY=your-secret-key

APP_HOST=0.0.0.0
APP_PORT=5000
APP_DEBUG=false

EXPORT_TEMP_DIR=/tmp

RRD_BASE_PATH=/opt/librenms-docker/compose/librenms/rrd
RRD_OUTPUT_CSV=cpu_combined.csv
MEMORY_OUTPUT_CSV=memory_combined.csv

RRD_LOOKBACK_DAYS=30
RRD_RESOLUTION=300

LIBRENMS_DB_HOST=localhost
LIBRENMS_DB_PORT=3306
LIBRENMS_DB_USER=librenms
LIBRENMS_DB_PASSWORD=your-password
LIBRENMS_DB_NAME=librenms

STORAGE_OUTPUT_CSV=storage_combined.tsv
```

**Never commit your `.env` file or real credentials to Git.**

## User Setup

The application uses `users.json` for local application authentication.

Create a user using:

```bash
python create_user.py
```

The generated `users.json` file should remain local and should not be committed to the repository.

Start the Flask application:

```text
http://localhost:5000
```

If the application is running on another server:

```text
http://SERVER_IP:5000
```

## Reports

### CPU

The CPU exporter reads `processor-hr-*.rrd` files and calculates:

* Minimum CPU usage
* Maximum CPU usage
* Average CPU usage

Additional device-specific RRD files are supported where applicable.

### Memory

The memory exporter searches for supported LibreNMS memory RRD files and calculates:

* Minimum memory usage
* Maximum memory usage
* Average memory usage

Memory utilization is calculated using:

```text
Used / (Used + Free) × 100
```

### Storage

The storage exporter queries the LibreNMS MySQL database and reports storage utilization for configured Linux and Windows partitions.

The generated report contains:

```text
Hostname
Partition usage percentages
```

## Docker

The project includes a `Dockerfile` for containerized deployment.

Build the image:

```bash
docker build -t librenms-exporter .
```

Run the container:

```bash
docker run -d \
  --name librenms-exporter \
  --env-file .env \
  -p 5000:5000 \
  librenms-exporter
```

### RRD Access

The container needs access to the LibreNMS RRD directory.

For example:

```bash
docker run -d \
  --name librenms-exporter \
  --env-file .env \
  -p 5000:5000 \
  -v /opt/librenms-docker/compose/librenms/rrd:/opt/librenms-docker/compose/librenms/rrd:ro \
  librenms-exporter
```

Adjust the paths according to your environment.

## Security

This project is intended to run in a trusted infrastructure environment.

For production deployments:

* Use a strong random `SECRET_KEY`.
* Never commit `.env`.
* Never commit `users.json`.
* Use a dedicated LibreNMS database account with appropriate permissions.
* Avoid running Flask with debug mode enabled.
* Restrict network access to the application where appropriate.
* Mount RRD data as read-only when possible.

## Configuration Reference

| Variable               | Description                      | Default                                     |
| ---------------------- | -------------------------------- | ------------------------------------------- |
| `SECRET_KEY`           | Flask session secret             | `dev-secret-key`                            |
| `APP_HOST`             | Flask bind address               | `0.0.0.0`                                   |
| `APP_PORT`             | Flask application port           | `5000`                                      |
| `APP_DEBUG`            | Flask debug mode                 | `false`                                     |
| `EXPORT_TEMP_DIR`      | Temporary export directory       | `/tmp`                                      |
| `RRD_BASE_PATH`        | LibreNMS RRD directory           | `/opt/librenms-docker/compose/librenms/rrd` |
| `RRD_OUTPUT_CSV`       | CPU exporter output filename     | `cpu_combined.csv`                          |
| `MEMORY_OUTPUT_CSV`    | Memory exporter output filename  | `memory_combined.csv`                       |
| `RRD_LOOKBACK_DAYS`    | Default RRD lookback period      | `30`                                        |
| `RRD_RESOLUTION`       | RRD resolution in seconds        | `300`                                       |
| `LIBRENMS_DB_HOST`     | LibreNMS database host           | `localhost`                                 |
| `LIBRENMS_DB_PORT`     | LibreNMS database port           | `3306`                                      |
| `LIBRENMS_DB_USER`     | LibreNMS database username       | —                                           |
| `LIBRENMS_DB_PASSWORD` | LibreNMS database password       | —                                           |
| `LIBRENMS_DB_NAME`     | LibreNMS database name           | —                                           |
| `STORAGE_OUTPUT_CSV`   | Storage exporter output filename | `storage_combined.tsv`                      |
